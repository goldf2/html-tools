    批量导入文稿

    整段粘贴，或选择多个 UTF-8 TXT / JSON 文件。支持“封面标题 / 标题＋口播 / 正文”、Markdown 标题和独占一行的 --- 分隔。只在本机按规则识别。

    尚未选择文件

    普通多段正文默认保留为一篇。没有明确标签的编号可能是步骤，只有确定每个编号都是一篇标题时，才开启上方选项。JSON 备份按原始标题、正文导入，不再拆分。

    可修改每篇的标题和正文，取消勾选不需要的稿件。正文为空的稿件也会保留，确认时只新增所选稿件。

    二维码共享

    一次共享一篇短文稿。长文稿或多篇文稿，请使用 JSON 导出文件。

    导出文稿

    仅下载文稿到当前设备，不上传，也不包含提词设置。正文含标题标签、分隔符或需保留首尾空白时，请选 JSON 备份。

    确认删除文稿

    可撤销最近一批删除，刷新后仍可撤销。新的删除会替换上一次撤销记录。
