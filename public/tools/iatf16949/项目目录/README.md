# IATF 16949 核心工具指南

面向汽车行业质量管理培训和实施讨论的静态资料页，整理 IATF 16949 与 APQP、PPAP、FMEA、MSA、SPC、Control Plan 之间的层级和业务流关系。

## 打开资料页

直接打开 `index.html`，或在项目目录运行：

```bash
python3 -m http.server 4173
```

然后访问 <http://localhost:4173>。

## 资料文件

- `iatf16949-core-tools-guide.md`：关系说明和实务映射
- `iatf16949-core-tools-flow.mmd`：业务流 Mermaid 源文件
- `iatf16949-core-tools-landscape.mmd`：全景关系 Mermaid 源文件
- `*.svg`：可直接预览的图形版本

内容用于培训和方案讨论，不替代受版权保护的标准正文；正式审核应以当前有效的标准、客户特殊要求和组织程序为准。
