# 统一工具箱

HTML Tools v1.1.0 将现有 9 个可用工具整合到一个工作区，不再逐个跳转独立页面。

## 使用入口

- 网站首页 `/` 进入 `/toolbox.html`，原 `?category=` 筛选参数继续有效。
- 本机直接打开 `public/toolbox.html`；旧 `public/offline.html` 保持可用，与新入口由同一模板生成。
- 左侧可搜索工具、按分类筛选；右侧使用当前工具。点击工具箱标识返回目录。
- 工具按需载入，已打开的页面在切换时保留，因此计算器未导出的累计、报价单输入和问卷填写不会因切换丢失。关闭或刷新整个工具箱后，按各工具原有草稿/导出能力恢复，不能把当前会话保留等同于所有工具都有持久化。
- 可以收起工具列表扩大工作区；手机使用抽屉工具列表。支持浏览器前进后退及 `#tool=工具ID` 定位。
- “单独打开”保留完整独立页面。报价打印使用报价工具原有按钮，只调用当前报价页面的打印功能。

## 归属与数据

9 个工具均属于现有 HTML Tools：口播提词器、工件重量计算器、IATF 16949 核心工具指南、产品及模具报价单生成器、高一兴趣爱好采集表、暑期旅游兴趣点采集表、家务抽奖大转盘、Markdown HTML Renderer、鹅鹏骑自行车。

没有新增项目、独立服务或业务数据库，没有把不同工具的业务数据合并。已有工具自身的存储键、草稿和导入导出机制保留。共享目录、菜单顺序与隐藏设置继续生效；原有隐藏条目不被重新显示。

本次交付的 `HTML工具箱.html` 使用原工具实体路径；报价入口指向之前交付的 `报价单生成器.html`，保留同一文件地址，便于继续使用该地址已有的浏览器草稿。`localHref` 仅供本机交付映射使用，网站忽略此字段。不同浏览器或不同网址之间仍通过原有草稿导入导出转移数据。

计算器、报价单及其他本机工具无需服务器。Markdown 工具的现有渲染依赖仍使用联网 CDN，整合没有改变其联网要求。

## 维护

- `scripts/workspace-template.html`：统一界面和交互，仅维护一份。
- `scripts/build-offline.mjs`：由同一工具目录和菜单配置生成 `public/toolbox.html` 与兼容入口 `public/offline.html`。
- `app/page.tsx`：网站首页进入统一界面。
- `public/site-nav.js`：嵌入时不重复显示门户导航；独立网站页面继续使用原导航。

新增工具仍登记到 `data/tools.json`，放入 `public/tools/`，执行 `npm run build`。不为每个单页另建项目。
