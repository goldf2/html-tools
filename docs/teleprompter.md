# 口播提词器 v1.0.0

目标：手机与 iPad 打开网页即可提词。用户确认本轮先完成文字版，语音留待后续。

- 页面：`public/tools/teleprompter.html`，单个 HTML，无框架运行依赖或外链资源。
- 访问路径：`https://tools.ebm01.com/tools/teleprompter.html`。
- 门户版本：1.0.5；提词器自身版本：1.0.0。
- 内置20条按优先级排列的宇峰机械口播文稿；不包含新机销售与回收置换推广。

## 使用

1. 选择内置文稿，或打开“编辑文稿”粘贴正文，也可导入 UTF-8 TXT。
2. 调整字号、速度；更多设置内可调整行距、镜像、倒计时及阅读指示线。
3. 点击开始，暂停后可继续；手动滑动正文会暂停，切后台也会暂停。
4. 手机可收起编辑区，iPad宽屏可显示编辑与提词两栏。专注模式扩大提词区域。
5. 支持网页全屏的浏览器可进入全屏，其余浏览器使用专注模式。屏幕唤醒按浏览器能力启用，不阻塞提词。

稿件修改、所选稿件和设置保存在当前浏览器本机，不向服务端上传正文、不跨设备同步。刷新后从文稿开头开始。再次导入TXT替换已有自定义文稿时，会先确认。

## 接入与发布

- 登记 `data/tools.json`、`data/menu-config.json`，通过原有 `/api/tools` 和门户发现入口。
- 沿用 Con01 / Coolify 的“网站与在线工具”项目 / production / “HTML 在线工具 · Web”既有资源。
- 应用 UUID：`gt1rf1g6ttpgdlj909uw5szd`；GitHub `goldf2/html-tools` 的 `main`；Nixpacks / Node；内部端口3000。
- 不新增资源、主机端口或持久化存储，不变更原域名与其他服务。
- 本地执行 `npm ci`、`npm run build`；提交并推送后检查既有部署，避免重复触发。
- 发布后核对部署提交、应用运行状态、首页工具入口、`/api/tools` 和提词器HTTP响应，并操作正式页面。
