# 口播提词器 v1.1.0

手机与 iPad 打开网页即可提词。用户确认本轮先完成文字版，语音留待后续。

- 页面：`public/tools/teleprompter.html`，单个 HTML，无外链运行依赖。
- 正式地址：`https://tools.ebm01.com/tools/teleprompter.html`，工具站首页也有入口。
- 本轮源码门户版本：1.0.6；提词器自身版本：1.1.0。
- 内置20条按优先级排列的宇峰机械口播文稿。

## 使用

1. 左侧列表点击标题切换文稿，选中项高亮；可点击“编辑当前文稿”或顶部“编辑”修改标题与正文。
2. “新增文稿”可添加多篇独立稿件；TXT导入也创建新稿，不覆盖已有稿件。
3. 编辑时自动保存，点击“完成，回到提词”返回。切稿和编辑会暂停并归零。
4. 701px及以上常驻左侧列表，手机窄屏使用“文稿列表”抽屉，选稿后自动收起。
5. 字号、滚速、行距、镜像、倒计时、阅读指示线及专注模式保持可用。
6. 网页全屏与屏幕唤醒按浏览器能力启用；不支持网页全屏时使用专注模式。

稿件与设置保存在当前浏览器本机，不上传服务端，也不跨设备同步。清理浏览器数据前需另存稿件。

## 本机数据升级

新版保存到 `yufeng.teleprompter.v2`，版本结构为2，包含 `drafts`、`titles`、`customScripts`、`selectedId` 与 `settings`。

v2不存在时只读导入旧 `yufeng.teleprompter.v1`，保留已编辑内置稿、非空 `__custom__` 稿和设置。旧键不删除、不改写，避免旧版已打开标签页关闭时覆盖新版新增稿。重复刷新不重复生成迁移稿。
