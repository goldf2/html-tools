# 口播提词器 v1.2.0

手机与 iPad 打开网页即可提词。用户确认本轮先完成文字版，语音留待后续。

- 页面：`public/tools/teleprompter.html`，单个 HTML，无外链运行依赖。
- 正式地址：`https://tools.ebm01.com/tools/teleprompter.html`，工具站首页也有入口。
- 本轮源码门户版本：1.0.7；提词器自身版本：1.2.0。
- 内置20条按优先级排列的宇峰机械口播文稿。

## 使用

1. 左侧列表点击标题切换，顶部“编辑”可修改当前文稿标题和正文，自动保存到本机。
2. “新增文稿”可逐篇添加；“批量导入”可整段粘贴多篇文案，或一次选择多个 UTF-8 TXT / JSON 文件。
3. 导入先预览识别结果，可修改标题、正文并勾选需要的稿件；确认后新增，不覆盖旧稿。
4. 自动识别明确的“封面标题/标题＋口播/正文”、Markdown标题和独占一行的 `---`。普通多段正文保守作为一篇；裸编号可在明确选择按编号分篇后拆分，避免误拆正文步骤。
5. 可删除当前稿，或在管理模式勾选、全选后批量删除。确认后执行；最近一次删除可撤销，刷新后仍保留撤销记录。开始新一批删除会替换上一次撤销记录。
6. 内置稿也可删除，删除后不会因刷新重新出现。全部删除后仍可新增或导入。
7. 导出当前稿、勾选稿或全部稿，提供 TXT 和 JSON 文稿备份。JSON 保留完整标题和正文，推荐换设备或备份时使用；重新导入仍经预览合并，不覆盖当前文稿。备份不包含提词设置或删除记录。
8. “二维码”可共享正式网址或当前短文稿。当前稿随链接fragment传递，在接收设备预览确认后新增；共享链接持有者可以读取文稿。长稿或多篇稿使用JSON文件传递。
9. 701px及以上常驻左侧列表，手机窄屏使用抽屉。切稿、编辑、导入和管理会暂停提词；字号、滚速、行距、镜像、倒计时、指示线及专注模式保持可用。

识别在浏览器本地完成，未调用云端AI。稿件与设置不上传服务端，也不自动跨设备同步。清理浏览器数据前请导出备份。

批量粘贴推荐格式：

```text
1.封面标题：第一篇标题
口播：第一篇正文，可以分成多段。

2.封面标题：第二篇标题
口播：第二篇正文。
```

## 本机数据升级

新版保存到 `yufeng.teleprompter.v3`，只在新键不存在时只读迁移 v2 或 v1。保留旧稿、标题、选中稿和提词设置，旧键不删除或改写，避免旧标签页关闭时覆盖新版稿件。

内置删除状态及最近一次删除记录也保存在新版键中。撤销只合并被删除的条目，不回滚整份库，因此不会覆盖删除后新建或编辑的文稿。
