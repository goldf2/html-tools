# 产品及模具报价单生成器

工具版本 1.1.1，门户版本 1.1.0。工具入口：`/tools/quotation-generator.html`。

## 使用

在工具中心选择“产品及模具报价单生成器”，或直接用浏览器打开对应 HTML 文件。页面自带标识，无运行外链；通过 file:// 打开时不加载门户导航和 API，可独立于 MES 与后端服务使用。

1. 填写报价标题、单位、日期、税率，可选填客户、编号和备注。
2. 编辑产品与费用项目，输入数量、未税单价和逐行备注；产品名称、行备注均支持手动换行。可添加、删除产品或费用项。
3. 预览按产品显示未税金额、税额与小计，底部显示未税合计、税额合计和含税总计。
4. 点击“打印 / 保存 PDF”，在浏览器打印界面选择 A4 纵向、100% 缩放，关闭浏览器页眉页脚。需要 PDF 时选择“另存为 PDF”。长报价自动分页，重复表头；长产品明细逐行显示产品身份，避免跨页合并单元格导致空白第一页。

产品名称列可固定为 24 至 42 mm，默认 32 mm，保留手动换行并自动折行；金额列按实际数字宽度调整，费用与备注列分配其余空间。短产品明细保留样张的合并产品名称结构；费用较多或备注较长时逐行显示产品身份。手机上编辑区适配窄屏，费用表与 A4 预览可在各自区域横向滚动。

公司 Logo 可上传 PNG、JPG、WebP（最大 5 MB），本机等比例处理并嵌入草稿；支持移除、隐藏和恢复默认 Logo。替换失败保留原图。自定义 Logo 不上传服务端，也不依赖外部图片链接。

新版草稿保存在当前浏览器的 `html-tools.quotation.v2`，首次只读接续旧版 `html-tools.quotation.v1`，旧记录保留；旧标签页继续保存也不会覆盖新版备注或 Logo。不同浏览器或网址的草稿不会自动互通。“导出草稿”保存完整 JSON，导入时确认替换当前内容，并重新计算金额。JSON 草稿上限 5 MB，包含 Logo、行备注和列宽；旧版无新增字段的草稿自动补齐默认值。未完成字段也可导出和恢复；存在错误时禁止页面的打印按钮，不显示上一次有效报价作为当前结果。新建和删除需确认，防止误操作。

## 金额口径

- 数量和未税单价最多 6 位小数；税率默认 13%，可在 0% 至 100% 之间编辑，最多 4 位小数。
- 数值采用十进制定点 BigInt 运算，避免二进制浮点尾差。
- 每行先将“数量 × 单价”四舍五入到分，再按该行金额计算税额并四舍五入到分；产品与整单按已舍入的行金额、行税额分别相加。
- 数字为非负数，整数最多 9 位；单行未税金额上限 999,999,999.99 元。最多 50 个产品、500 行费用项；数字限制由计算验证，产品及行数上限在 UI 和导入中验证。
- JSON 中存输入字符串，不保存可篡改的计算结果。无效 JSON 或字段结构不会替换当前报价；用户文本按文本转义显示。
